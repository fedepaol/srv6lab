# Implementation Plan: PE1 as EVPN Route Reflector

**Branch**: `004-pe1-evpn-route-reflector` | **Date**: 2026-04-24 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/003-pe1-evpn-route-reflector/spec.md`

## Summary

Move l2vpn evpn route reflection from TOR to PE1. PE2/PE3 peer with PE1 for l2vpn evpn. TOR loses l2vpn evpn AF entirely. PE1 has dual role: VTEP + route reflector. Template needs refactoring — l2vpn evpn section becomes variable-driven since PE1/PE2/PE3 each need different neighbor configs.

## Implementation Details

### Key Challenge: Template Refactoring

Current template has a single `${PEER_ADDR}` neighbor used for all AFs. l2vpn evpn now needs different peers per PE. Solution: replace the hardcoded l2vpn evpn AF block with two template variables:

- `${L2EVPN_NEIGHBORS}` — BGP neighbor declarations for EVPN peers (global BGP section)
- `${L2EVPN_AF_BLOCK}` — entire l2vpn evpn address-family block

### 1. Modified template: `templates/pe-frr.conf.tpl`

Add `${L2EVPN_NEIGHBORS}` after existing neighbor declarations (before first AF).

Replace the l2vpn evpn AF block with `${L2EVPN_AF_BLOCK}`.

### 2. Modified: `generate.sh`

Per-PE L2EVPN variable values:

**PE1** (route reflector — peers with PE2 fc00:0:2::1 and PE3 fc00:0:3::1):
- Declares PE2/PE3 as neighbors with update-source fc00:0:1::1
- l2vpn evpn AF: activate PE2/PE3, mark both as route-reflector-client
- advertise-all-vni, advertise-svi-ip

**PE2** (client — peers with PE1 fc00:0:1::1):
- Declares PE1 as neighbor with update-source fc00:0:2::1
- l2vpn evpn AF: activate PE1
- advertise-all-vni, advertise-svi-ip

**PE3** (client — peers with PE1 fc00:0:1::1):
- Declares PE1 as neighbor with update-source fc00:0:3::1
- l2vpn evpn AF: activate PE1
- advertise-all-vni, advertise-svi-ip

**RemotePE** (no EVPN):
- Both variables empty

### 3. Modified: `tor/frr.conf`

Remove l2vpn evpn address-family block. Keep ipv4 vpn and ipv6 vpn unchanged.

### 4. Regenerate configs

Run `generate.sh` to regenerate pe1/, pe2/, pe3/, remotepe/.
